## 常见追问

**为什么不直接让 ChatGPT 分析 CSV？**

这里关注的是可复现查询流程、明确指标口径和执行限制。每个结果都有 SQL、表格与轨迹，失败和边界可测试。项目规模小，不能声称比通用工具整体更强。

**你解决了哪些工程问题？**

下载数据可重建与追溯；SQL AST 加数据库权限防护；受限执行与行数上限；一次错误修复；模拟模型控制流测试；独立 CSV 参考答案；界面模式透明。

**为什么不用 LangGraph、多 Agent 或 PostgreSQL？**

只有一个数据表和短状态流程，直接 Python 更便于理解和测试。引入框架要有实际需求。未来多表、多用户和复杂恢复才可能改变选择。

**项目里什么最容易产生错误结论？**

把观察数当客户数、把跨年月份当时间序列、把相关当因果、用通话后 duration 做通话前预测、忽略 unknown/999 的语义、用小样本最高转化率决定投放。

**你怎样知道模型真的正确？**

目前演示 SQL 由独立 CSV/Python 参考答案核对。真实模型需要单独跑 live 评测，再添加未见改写、模糊问题、攻击和人工业务语义评审。不能用单元测试通过率代替模型效果。

**AI 写了很多代码，你自己的贡献怎么证明？**

诚实说明 AI 辅助，展示你亲自独立完成的修改、失败定位、口径解释和 commit；现场完成一个新分组问题。没有完成学习前，不声称自己理解全部架构。
